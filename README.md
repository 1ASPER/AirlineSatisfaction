# Airline Satisfaction

My solution for the [Kaggle Playground S6E10](https://www.kaggle.com/competitions/playground-series-s6e10) competition.

**Task:** Predict passenger satisfaction probabilities.
**Metric:** ROC-AUC.

## Usage
1. Install dependencies: `pip install -r requirements.txt`
2. Download competition data into `data/`.
3. Run `notebooks/baseline.ipynb`.

Predictions are saved to `submissions/`.
